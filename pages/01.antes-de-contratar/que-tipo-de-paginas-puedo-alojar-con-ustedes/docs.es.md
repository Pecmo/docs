---
title: '¿Qué tipo de páginas puedo alojar con ustedes?'
date: '00:32 22-02-2026'
taxonomy:
    category:
        - docs
visible: true
---

Puedes tener cualquier tipo de página web alojada con nosotros: blogs, páginas personales, portafolios, sitios corporativos, galerías de imágenes, foros de discusión, wikis, páginas de captura (landing pages), sitios de transmisión de videos, podcasts, etc.

El único contenido que no permitimos es lo siguiente:

* Páginas de distribución de piratería (warez) de cualquier tipo: audio, video, software, ebooks, etc.
* Páginas de distribución de aplicaciones para vulnerar seguridad (hacking).
* Páginas que contengan cualquier tipo de pornografía infantil.
