---
title: ' ¿Puedo transferir y/o contratar un dominio únicamente?'
date: '00:30 22-02-2026'
taxonomy:
    category:
        - docs
visible: true
---

Por supuesto, contamos con servidores DNS propios que nos permiten administrar cualquier tipo de dominio. Si deseas contratar y/o transferir únicamente un dominio con nosotros, lo puedes solicitar, realiar el pago correspondiente y esperar de 24 a 48 horas para ver el dominio funcionando.

Para la transferencia del dominio únicamente requerimos el código EPP o código de desbloqueo. Si no cuentas con éste, lo puedes solicitar a tu proveedor actual.
